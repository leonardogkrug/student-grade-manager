Sistema de Cadastro de Alunos e Notas

Projeto desenvolvido durante o primeiro semestre do curso de Ciência da Computação da Universidade do Vale do Rio dos Sinos (Unisinos).

-> Sobre

Este projeto consiste em um sistema de gerenciamento de alunos desenvolvido em linguagem C. O programa utiliza arquivos binários para armazenar as informações de forma permanente, permitindo cadastrar alunos, consultar registros, alterar notas e calcular a média geral da turma.

O projeto foi desenvolvido como atividade acadêmica com o objetivo de praticar conceitos fundamentais da programação e da manipulação de arquivos.

-> Objetivo

Praticar os conceitos estudados durante o primeiro semestre da graduação, com foco em:

- Lógica de programação
- Organização do código em funções
- Manipulação de estruturas (struct)
- Manipulação de arquivos binários
- Entrada e saída de dados
- Desenvolvimento de aplicações em linguagem C

-> Funcionalidades

- Cadastro de alunos
- Armazenamento permanente em arquivo binário (alunos.dat)
- Consulta de alunos cadastrados
- Alteração de notas
- Cálculo da média geral da turma

-> Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão da linguagem C
- Arquivos binários

-> Conceitos aplicados

- Estruturas (struct)
- Funções
- Manipulação de arquivos (fopen, fread, fwrite, fseek)
- Controle de fluxo
- Vetores
- Entrada e saída de dados

-> Como executar

Abra o projeto em uma IDE compatível com a linguagem C (como Visual Studio Code ou Code::Blocks), compile o arquivo principal e execute o programa.

Na primeira execução, o arquivo `alunos.dat` será criado automaticamente para armazenar os registros dos alunos.

-> Melhorias futuras

Este projeto continuará sendo evoluído ao longo da graduação conforme novos conceitos e técnicas forem aprendidos.

Algumas melhorias planejadas incluem:

- Exclusão de alunos
- Pesquisa por nome
- Ordenação dos registros
- Melhor tratamento de entradas inválidas
- Interface mais organizada
- Otimização do código
